# AWS S3 + CloudFront Static Website

## Project Overview
This project demonstrates how to host a static website using Amazon S3 and improve performance and delivery using Amazon CloudFront.

## Services Used
- Amazon S3
- Amazon CloudFront

## Features
- Static website hosting on S3
- Content delivery through CloudFront
- Global caching for faster access

## Live Demo
[http://dlncw9aoytnv4.cloudfront.net](https://dlncw9aoytnv4.cloudfront.net/)

## Key Learnings
- Hosting static websites on AWS S3
- Configuring bucket permissions and static website hosting
- Using CloudFront to deliver content globally
